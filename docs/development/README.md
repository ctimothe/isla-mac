# Development docs

For contributors. You don't need any of this to use Isla.

| File | What it is for |
| --- | --- |
| [spec.md](spec.md) | What Isla does today and the rules it keeps. The behaviour contract: change it in the same commit as the behaviour. |
| [open-checks.md](open-checks.md) | What is still owed: hardware checks on a notched MacBook, open findings and open owner decisions. |
| [plans/2026-11-15-islandcn-identical.md](plans/2026-11-15-islandcn-identical.md) | The active plan: islandcn's island, activities, icons and motion, slice by slice. |
| [audits/2026-11-15-islandcn-identical/](audits/2026-11-15-islandcn-identical/) | The plan's inputs: islandcn's motion, activities and icons, measured against Isla. |

These describe the app as it is. Finished plans, audits, research and the
history of every decision are in git: `git log -- docs/development`.

How to verify and ship a release is in [../runbook.md](../runbook.md) and
[../release-checklist.md](../release-checklist.md).
