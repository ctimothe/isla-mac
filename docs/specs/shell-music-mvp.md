# Historical shell and Music MVP spec

> **Status: historical and non-binding.** This file records the earlier
> shell/Music prototype direction. It is not the current product contract and
> must not be used to decide implementation or release readiness.

The binding specification is the approved
[Dynamic Island — Cyclop 0.6.5 Parity Design](../plans/2026-08-18-dynamic-island-parity-design.md).
That design supersedes the prototype by covering the complete nine-tab product,
synthetic-notch behavior, isolated persistence, permissions, performance,
original identity, packaging, and eleven release gates.

The prototype branch remains useful only as historical context. New work should
start from the parity implementation and its tested interfaces.
