## What's new

- Review follow-ups for the unconfirmed tap, a replaced file, Quick Look and long text
- VoiceOver reads Translate To by name, and the sweep opens every Settings section
- Translate stops reading when its Stop is gone, keeps a half-translated text and reads the clipboard only when it may
- Clipboard finds what its rows show, asks about what it will clear and keeps long text whole
- The Shelf keeps a renamed file, gives Delete back and answers a drop honestly
- Play and pause never get stuck, lag a skip or outlive their player

## Install

Already running a release after 0.3.0? Isla offers this one on the island by itself: press **Install**.

New to Isla, or on 0.3.0 or earlier:

1. Download `Isla-0.4.1.dmg` below, open it and drag **Isla** to **Applications**.
2. This build is not notarized yet, so remove the download quarantine once:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Isla.app
   ```

3. Open Isla from Applications.
