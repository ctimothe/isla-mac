# Isla v0.2 "Front Door" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Isla installable, correct on first contact, and discoverable — a release whose entire content is the front door, with no new capability.

**Architecture:** Every finding from the 2026-09-03 audit that this release closes is encoded as a failing test or a dated design-doc amendment before it is fixed, so it cannot regress silently. Three correctness defects (a crash on an advertised drop path, a dead hit region on synthetic notches, a pin that the pointer never clears) are fixed against new tests. One new release gate measures the *outside* view — whether a downloaded copy passes Gatekeeper — which is the class of failure the existing ten gates structurally cannot see. A first-run pane inside the existing panel body gives a `.accessory` app its first visible moment.

**Tech Stack:** Swift 6.0 tools / language mode v5, `platforms: [.macOS(.v15)]`, SwiftPM only (no Xcode project), XCTest, AppKit + SwiftUI, bash release gates.

## DECISION REQUIRED BEFORE TASK 2

`NotchShape.fill(Color.black)` (`NotchContentView.swift:74`) draws the synthetic notch at full `notchSize.height` **at all times**, not only while media plays — only the *header* falls back to `Color.clear` (`:153-155`). So on every external display a permanently visible black pill has ~75 % of its surface dead to clicks, because `collapsedDepth` is `8` there.

Raising the hit region to the drawn height fixes the island and **takes clicks away from menu-bar status items underneath it**. `NotchGeometry.swift:275-282` records the measurement: on a 13" M1 status items start at x≈757 while the synthetic notch spans 630…810. Those items are *already* visually covered by the black shape; today they remain clickable while invisible.

- **Option A (recommended):** full drawn height. An island you can see and click beats a status item you cannot see but can click. Ship a Settings escape hatch only if someone reports it.
- **Option B:** keep 8 pt, and stop drawing the synthetic notch full-height when idle so the visible shape matches the live region.

Task 2 below is written for **Option A**. If Option B is chosen, Task 2's fix step changes to a `NotchContentView` height change and the test asserts the drawn height instead.

### Task 1: A promised file arriving off the main queue must not take the app down

**Files:**
- Modify: `Sources/IslaKit/Notch/NotchRootView.swift:228-240`
- Test: `Tests/IslaKitTests/ShelfDropTests.swift` (create)

**Interfaces:**
- Consumes: nothing from earlier tasks.
- Produces: `NotchRootView.promisedFileArrived(_ url: URL?, error: Error?)` — `nonisolated`, safe to call from any queue. Later tasks do not depend on it.

**Background:** `performDragOperation` hands `NSFilePromiseReceiver` a fresh `OperationQueue` (`:227-228`, deliberately not the main queue — the reader is wrapped in an `NSFileCoordination` read that blocks). The reader body then calls `MainActor.assumeIsolated`, which traps when the assertion is false. It always is. Mail attachments, Photos items and browser images are exactly the sources `:74-76` registers the promise types for.

- [ ] **Step 1: Write the failing test**

```swift
import XCTest
@testable import IslaKit

/// The promised-file path, driven the way `NSFilePromiseReceiver` drives it.
///
/// It hands its reader to the operation queue the caller supplied, which is
/// deliberately not the main queue. Asserting main-actor isolation inside that
/// reader is not a check that fails loudly in the wrong case — it is a trap
/// that takes the process down every time a Mail attachment or a Photos item
/// lands on the shelf.
@MainActor
final class ShelfDropTests: XCTestCase {

    func testAPromisedFileArrivingOffTheMainQueueIsDelivered() {
        let view = NotchRootView(frame: .zero)
        let delivered = expectation(description: "the coalesced batch reaches onDrop")
        var received: [URL] = []
        view.onDrop = { urls in
            received = urls
            delivered.fulfill()
            return true
        }

        let url = URL(fileURLWithPath: "/tmp/isla-promise-test.txt")
        let queue = OperationQueue()
        queue.qualityOfService = .userInitiated
        queue.addOperation { view.promisedFileArrived(url, error: nil) }

        wait(for: [delivered], timeout: 3)
        XCTAssertEqual(received, [url])
    }

    /// A cancelled or failed promise still calls the reader, with an error.
    /// It must be logged and dropped, never delivered as a file.
    func testAFailedPromiseDeliversNothing() {
        let view = NotchRootView(frame: .zero)
        view.onDrop = { _ in
            XCTFail("a failed promise must not reach the shelf")
            return false
        }

        let queue = OperationQueue()
        queue.addOperation {
            view.promisedFileArrived(nil, error: CocoaError(.userCancelled))
        }

        let settled = expectation(description: "the coalesce window closes")
        DispatchQueue.main.asyncAfter(deadline: .now() + 1.0) { settled.fulfill() }
        wait(for: [settled], timeout: 3)
    }
}
```

### Task 4: A gate that measures the outside view

**Files:**
- Create: `Scripts/test-gatekeeper.sh`
- Modify: `.github/workflows/build.yml:22`
- Modify: `CLAUDE.md` (repo root, on `main`) — the gate order list. Do this in Task 5's docs commit.

**Interfaces:**
- Consumes: `build/Isla.app` produced by `Scripts/bundle.sh release`.
- Produces: an executable gate that exits non-zero when a **signed** build would fail Gatekeeper, and skips loudly when the build is ad-hoc.

**Background:** the ten existing gates check provenance, branding, localization parity, bundle identity, the helper contract, the package contract and helper lifecycle. Every one measures internal consistency. None asks whether a downloaded copy launches. That gap is why an ad-hoc-signed `libislamedia.dylib` shipped: `spctl -a -t open` rejects it, `/usr/bin/perl` refuses to load it under quarantine, and the user is offered **Move to Trash** on the app's own media helper.

The gate must not fail the ad-hoc developer loop, which is legitimate — `bundle.sh:113` defaults `SIGN_IDENTITY` to `-` on purpose. It branches on `DEVELOPER_ID_APPLICATION` exactly as `bundle.sh` does.

- [ ] **Step 1: Write the gate**

Create `Scripts/test-gatekeeper.sh`:

```bash
#!/bin/bash
# Единственный гейт, который смотрит на приложение снаружи.
#
# Остальные десять проверяют внутреннюю согласованность: происхождение,
# брендинг, паритет локализаций, идентичность бандла, контракт хелпера,
# состав пакета, его жизненный цикл. Ни один не спрашивает, запустится ли
# скачанная копия. Именно поэтому в релиз ушёл libislamedia.dylib с ad-hoc
# подписью: spctl его отклоняет, /usr/bin/perl отказывается загрузить его
# под карантином, и пользователю предлагают «Move to Trash» — то есть удалить
# медиа-хелпер собственного приложения.
#
# Ad-hoc сборка — законный режим разработки (см. bundle.sh:113), поэтому гейт
# ветвится по DEVELOPER_ID_APPLICATION ровно так же и громко пропускает себя.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
APP="${1:-$ROOT/build/Isla.app}"
DYLIB="$APP/Contents/Resources/libislamedia.dylib"

fail() { echo "!!! $1" >&2; exit 1; }

[ -d "$APP" ] || fail "нет бандла: $APP (сначала ./Scripts/bundle.sh release)"
[ -f "$DYLIB" ] || fail "в бандле нет helper dylib: $DYLIB"

if [ -z "${DEVELOPER_ID_APPLICATION:-}" ]; then
    echo "  ~ DEVELOPER_ID_APPLICATION не задан: ad-hoc сборка."
    echo "  ~ Gatekeeper ЗАБЛОКИРУЕТ такую сборку у пользователя:"
    echo "    dlopen хелпера в /usr/bin/perl будет отклонён системной политикой."
    echo "  ~ Гейт пропущен. Релиз обязан идти через Scripts/release.sh."
    exit 0
fi

# Обе части подписи. Вложенный dylib проверяется отдельно, потому что именно
# он ломался: бандл может быть подписан верно, а вложенный код — нет.
for target in "$APP" "$DYLIB"; do
    codesign --verify --strict --deep-verify "$target" 2>/dev/null \
        || codesign --verify --strict "$target" \
        || fail "подпись не проходит проверку: $target"
    codesign -dvvv "$target" 2>&1 | grep -q "TeamIdentifier=[A-Z0-9]\{10\}" \
        || fail "нет TeamIdentifier — подписано ad-hoc: $target"
done
```

```markdown
### Amendment — 2026-09-10: the collapsed target is the drawn shape on every display

The design specifies a collapsed target the size of the notch. The
implementation narrowed that to an 8 pt strip on synthetic notches, to leave
menu-bar status items underneath reachable. Since `NotchShape` fills black
unconditionally, the pill is visible at all times there, and the strip left
roughly three quarters of a visible island dead. Reversed: the target is the
drawn shape everywhere. Status items under a synthetic notch are already
hidden by it, and a visible target that works is worth more than an invisible
one that does. Held by `CompactHitAreaTests`.

### Amendment — 2026-09-10: the click that opens also closes

The 2026-08-26 amendment made the panel open on a click and said nothing about
closing it. In practice a clicked-open panel pinned itself and neither a second
click nor the pointer leaving could release it — only a click elsewhere on
screen. A click on the island now toggles, and the pointer arriving clears the
pin regardless of the Open on Hover setting, which governs whether arriving
*opens* and never whether arriving takes back a panel already open. Held by
`OpenOnClickTests`.

### Amendment — 2026-09-10: distribution is a gate, not a final step

The design treats signing and notarization as release mechanics. They are a
behaviour contract: an ad-hoc-signed `libislamedia.dylib` is refused by
`/usr/bin/perl` under quarantine, so an unsigned build silently loses the
MediaRemote path and falls back to AppleScript — Music and Spotify only — while
telling the user nothing. `Scripts/test-gatekeeper.sh` now measures this, and
it is the first gate that looks at the app from outside.
```
